# Healthy Fitness

A Flutter fitness app with Google sign-in, user profiles, workout detail and history, daily goals, trainer live-session modes (UI), and real-time step tracking.

## Features

- **Google sign-up / login** — Firebase Auth; first Google sign-in creates your account automatically
- **Profile** — Display name, fitness goal, photo from Google; saved to Firestore
- **Workouts** — Tap a quick workout for exercises and **Mark workout complete**
- **Workout history** — Completed sessions stored per user in Firestore
- **Home dashboard** — Goals, quick workouts, live training modes, step progress
- **Real-time steps** — Device pedometer with daily baseline (starts at 0 each day)

## Requirements

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (Dart 3.9+)
- A [Firebase](https://console.firebase.google.com/) project with **Authentication → Google** and **Cloud Firestore** enabled
- Physical phone recommended for step counting

## Firebase setup

1. Create a Firebase project and register Android + iOS apps (bundle ID / package: `com.example.healthy_fitness`).
2. Enable **Google** as a sign-in provider in Firebase Authentication.
3. Install CLI tools and generate config:

   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```

   This overwrites `lib/firebase_options.dart` and adds `google-services.json` / `GoogleService-Info.plist`.

4. **Android**: Add your debug SHA-1 in Firebase Console (Project settings → Your apps → Android → Add fingerprint).  
   Get SHA-1: `cd android && ./gradlew signingReport`

5. **Firestore**: Create database (test mode for development), then deploy rules:

   ```bash
   firebase deploy --only firestore:rules
   ```

   Rules file: `firestore.rules` (users can only read/write their own data).

**Manual Android file (if not using FlutterFire):** Download `google-services.json` from Firebase Console → Project settings → Your Android app, and place it at:

`android/app/google-services.json`

See `android/app/google-services.json.example` for the expected shape.

## App flow

1. **Login** — Continue with Google  
2. **Home** — Workouts, steps, live modes  
3. **Workout detail** — Exercises → Mark complete → saved to history  
4. **History** (app bar) — Past completed workouts  
5. **Profile** (app bar) — Edit profile, sign out  

## Firestore structure

```
users/{uid}
  email, displayName, photoUrl, fitnessGoal, dailyStepGoal, updatedAt

users/{uid}/workoutHistory/{autoId}
  workoutId, workoutTitle, durationMinutes, completedAt
```

## Step tracking

Uses `pedometer` + daily baseline in `shared_preferences`:

`today’s steps = sensor steps − baseline (reset each calendar day)`

| Platform | Permission |
|----------|------------|
| Android | `ACTIVITY_RECOGNITION` |
| iOS | Motion & Fitness (`NSMotionUsageDescription`) |

## Troubleshooting

### `google-services.json is missing`

The app can build **without** that file (Google Services plugin is applied only when the file exists). For **Google sign-in** you must add the real file from Firebase (or run `flutterfire configure`), then rebuild:

```bash
flutter clean
flutter run
```

### Google account picker opens, then nothing happens

1. Run `flutterfire configure` (replaces `lib/firebase_options.dart`).
2. Place `google-services.json` in `android/app/`.
3. Firebase Console → Project settings → Android app → add **SHA-1** fingerprint:
   ```bash
   cd android && ./gradlew signingReport
   ```
4. Firebase Console → Authentication → Google → copy **Web client ID**, then run:
   ```bash
   flutter run --dart-define=GOOGLE_WEB_CLIENT_ID=YOUR_WEB_CLIENT_ID.apps.googleusercontent.com
   ```

The login screen shows a warning if Firebase still uses placeholder keys (`YOUR_*` in `firebase_options.dart`).

### `package:garibook/...` or `FlutterGeolocator` in logcat

Those lines come from **another app** on the phone (different process ID), not Healthy Fitness. You can ignore them unless you are debugging Garibook.
